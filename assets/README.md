# Assets

Place sprite sheets, tilemaps, audio files, and fonts here. Organize by type:

- `assets/sprites/` — Character sprites, machine sprites, UI icons
- `assets/audio/` — Sound effects, ambient loops, music tracks
- `assets/fonts/` — Bitmap fonts or TTF/OTF files
- `assets/tilemaps/` — Tiled JSON/CSV maps and tilesets
